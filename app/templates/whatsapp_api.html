Como configurar (uma vez)

  1. Pegue os dois IDs Em developers.facebook.com → seu app → WhatsApp → Configuração da API: copie o ID do número de telefone e o ID da conta do WhatsApp Business.
  2. Gere o token permanente Configurações do negócio → Usuários do sistema → crie um usuário admin → Gerar token com whatsapp_business_messaging e whatsapp_business_management, sem validade.
  3. Ligue o webhook Em WhatsApp → Configuração, URL de callback {{ webhook }} e o token de verificação que você inventar abaixo. Assine o campo messages. O segredo do app (Configurações do app → Básico) deixa o sistema conferir que o aviso veio da Meta.
  4. Crie e aprove os modelos Em Gerenciador do WhatsApp → Modelos de mensagem: um para a promoção, com as variáveis escritas abaixo, e, se quiser, um de Utilidade para a confirmação de cadastro. Depois da aprovação, informe os nomes aqui.
  5. Teste e ligue Mande uma mensagem de teste. Depois, ligue o envio automático.
