Como funciona

  • Use um chip separado. O leitor funciona como o WhatsApp Web; a Meta pode bloquear o número. Nunca ligue o número que fala com os clientes.
  • O número só lê. Ele não envia nada, não responde e não aparece para os clientes.
  • Texto de passagem é lido na hora pelas regras. Imagens, hotéis, pacotes e cruzeiros passam pela IA {% if ia_ligada %}(ligada {{ leituras_hoje }} de até {{ max_leituras }} leituras hoje{% if pendentes %}, {{ pendentes }} esperando{% endif %}){% else %}(desligada falta GEMINI_API_KEY no Render; imagens ficam de fora){% endif %}.
  • Só os grupos marcados como lidos entram. Grupos novos em que o número entrar aparecem aqui desligados.
  • Depois de uma publicação do sistema, o número religa sozinho (a sessão fica guardada).
